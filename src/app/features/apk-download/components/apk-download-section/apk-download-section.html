¿Cómo genero el hash del archivo?

Linux

sha256sum prestamesta.apk

macOS

shasum -a 256 prestamesta.apk

Windows PowerShell

Get-FileHash .\prestamesta.apk -Algorithm SHA256

El hash solo aporta confianza si lo obtienes de una fuente legítima y protegida, como esta página oficial.
