Seguridad

Cómo aborda PrestaMesta la seguridad

La seguridad no es una función adicional: forma parte de cada decisión de diseño.

Este proyecto es una entrega académica para las materias de Arquitectura de Software y Seguridad Informática. Por eso distinguimos con cuidado entre tres cosas muy distintas: lo que ya está implementado en esta página, lo que se propone para una futura aplicación móvil, y lo que dependería de un backend real que hoy no existe. No afirmamos contar con auditorías, certificaciones o cumplimiento legal que no se hayan realizado.
